# 分身术（dsh-fenshenshu）

> 英文名 / 包名：`dsh-fenshenshu`。中文叫分身术 —— 一个本体，多个分身。

给 DSH 装一个「本体 + 分身」的骨架：一个会话当本体，其余会话当分身；
分身干活、学东西，写完提案交回本体审，本体才长。

> 这套东西是**纯本地文件 + 几个 python 脚本**，不联网、不收集数据，你机器上的东西不出机器。

## 它解决什么

同一个机器开多个窗口，每个都从零开始：学得慢、忘得快、说的话还不一样。

分身术的做法：
- 选一个会话当**本体**，其余当**分身**
- 给每个分身划**分区**（只允许读哪几份文档、只用哪几个工具）
- 分身学到的东西写成**提案**，本体审过才进正文
- 分身**不能审自己**的提案

## 30 秒上手

```powershell
# 1. 建骨架（在当前目录铺一个 body/）
python init.py

# 2. 填人设：body/shenfen/人设.md —— 你的鱼怎么说话

# 3. 把你的旧资料归进来（只出清单，看过才动）
python 导入.py D:\我的旧资料
python 导入.py D:\我的旧资料 --apply

# 4. 工作区太乱就理一下（同样是先出清单）
python 整理.py
python 整理.py --apply

# 5. 起面板
python panel.py          # → http://127.0.0.1:9888/
```

## 面板能干什么

- **分身表**：每间屋的 role（主窗口 / 工作 / 语言）和分区（可多选）
- **登记分身**：先把身份和分区定下来（窗口在 DSH 里自己建）
- **待审提案 / 建议**：看队列，点「请主窗口审」就排进审核队列
- **交卷状态**：谁干了活没交卷，一眼看得出来

## 目录长什么样

```
body/
  shenfen/   人设、自我、说话方式      ← 我的脸，只有我能改
  lingyu/    五个域：语言/群聊/声音/工作/记忆
  jiyi/      每个分身一个记忆目录
  jianyi/    建议栏（一行一条）
  daishen/   提案区（本体审过才合并）
  jinqi/     近期事件（所有窗口都写）
  zhishi/    知识库      yuliao/  语料
  huihua/    每间屋的档案（role + domains）
  renwu/     任务卡 + 催交清单
```

## 三条硬规矩

1. **分身只能写** `jiyi/<自己>/`、`jianyi/<自己>.md`、`daishen/`、`jinqi/`
2. **改正文必须投提案**，本体审过才合并 —— 分身不能审自己的
3. **工具按分区裁**：没勾的分区，对应工具直接没有；撞上了说一句「不在我的工作范围」，不许绕

## 分区（和本体那套一模一样）

| 行为域 | 管什么 |
|---|---|
| 语言 | 怎么说话：嘴、句式、长度、禁语 |
| 群聊 | 在群里怎么活：规矩、复读、频率、梗 |
| 声音 | 发语音、唱歌、声线 |
| 工作 | 修机器、插件、命令、踩过的坑 |
| 记忆 | 管本体：记忆、提案、审核 |

| 素材库（可选，吃 token） | 管什么 |
|---|---|
| 知识库 `zhishi/` | 查资料攒下来的知识 |
| 梗库 `shenfen/梗百科.md` | 用的梗、出处 |
| 语料 `yuliao/` | 真人说话的样本 |
| 表情指路 `zhishi/表情指路.md` | 什么场合发哪张图（只写路径，不含图） |

**勾得越多越费 token**：行为域每份 1~8KB，素材库可能十几到几十 KB。只勾真要用的。

## 交卷机制（核心）

干了活要交卷：**记过程（`jiyi/`）→ 记发现（`jianyi/`）→ 要改正文的投 `daishen/`**。

判断是自动的，不靠自觉：
- `toolgate` 插件在**每轮结束时**看这轮干了什么；调用了 ≥2 次工具却没往 `jiyi`/`jianyi`/`daishen` 写东西 → 记一笔欠账
- **交卷后自动清零**；欠几次会累加（`body/renwu/_催交.json` 是数据，`_催交.md` 是渲染出来的清单）
- 全过程只读写本地文件，**不花 token**

看欠账有两个地方：
1. `body/renwu/_催交.md`（清单）
2. 面板的分身表 → 「交卷」列

再装 `bubble/` 那个插件，界面右下角会挂一个小气泡：可拖动、位置记住、点 `−` 缩成圆点、有新欠账冒红点、点「面板↗」直接开面板。

## 工具闸插件（可选）

`toolgate/` 是一个 DSH 插件：按 `huihua/<会话>.json` 的 `domains` 决定分身**能用哪些工具**，
顺带做上面说的**交卷检查**。
没勾「表情指路」的分身，直接没有发图工具；撞上了会说「这不在我的工作范围」，不许绕。

装法（DSH 应用里）：
1. 插件页 → `+ 添加插件`
2. 填本地目录：`<你放这个包的目录>\toolgate`
3. 重启 DSH

## 三个脚本的分工

| 脚本 | 干什么 | 动不动文件 |
|---|---|---|
| `init.py` | 铺骨架 | 只创建，不覆盖 |
| `导入.py` | 旧资料 → 分区（出清单） | 默认只复制；`--pick` 逐条问「待定」，`--apply` 时问复制还是剪切 |
| `整理.py` | 工作区分盒（出清单） | 只移动，不删除 |
| `panel.py` | 网页面板 | 只改 `huihua/` 和提案状态 |
| `ziji.py` | 分身自检：我该读什么、欠没欠交卷 | 只读 |
| `jianyi.py` | 标建议状态：`--mark <会话> <行号> "已看/已采纳/已修/不收(理由)"` | 只改状态 |
| `hebing.py` | 审提案：`--review <文件> --by 大肥鱼` 合并；`--reject --why "理由"` 驳回。**分身不能审自己的** | 改正文 + 归档提案 |
| `bubble/` | 界面内气泡（DSH 插件） | 只读 |
